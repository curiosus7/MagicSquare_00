---

### 1) 주제 (한 문장)

> **4×4 부분 마방진에서 빈칸을 채운 직후, 행·열·대각선 10선이 각각 34인지 빠르게 확정하고, 틀리면 어느 줄인지 바로 짚을 수 있게 검증 규칙과 테스트 루프를 만든다.**

*(솔루션 최소화 — 앱·솔버·ECB 도구가 아니라 **판정·확인 비용**만 다룸)*

---

### 2) R-G-I-O

| | 내용 |
|---|---|
| **R — Role** | 4×4 **부분** 마방진 학습자. 빈칸 2개(0)를 1~16으로 채운 뒤 **맞았는지 스스로 확인**해야 함 |
| **G — Goal** | 빈칸 채운 후 **10선 합 34 여부를 즉시 판정**하고, 틀리면 **어느 행·열·대각선**인지 식별 *(20분 낭비 → 처음·한 번에)* |
| **I — Input** | `grid: list[list[int]]` — 4×4 정수 격자. 셀 값 **0**(빈칸) 또는 **1~16** |
| **O — Output** | `validate_lines(grid)` → ValidationResult: `ok`, `status`, `lines[]` (fail 시 틀린 줄 ID·sum·expected) |

---

### 3) 성공 기준 3개 (Mom Test 증거 연결)

| # | 성공 기준 | 연결 증거 |
|---|-----------|-----------|
| 1 | **10선×34 검증**을 한 Command로 수행 | “**대각선 하나를 빼먹어서**” |
| 2 | Test Loop Red→Green (합≠34 Red, 정답 Green) | “**20분 날렸다**” |
| 3 | fail 시 **어느 줄**인지 Output에 명시 | “맞는지 **판정하지 못하고**” 반복 |

---

### 4) 표면 문제 — 이번 프로젝트에서 하지 않을 것

- `SquareValidator` 검증기 프레임워크
- 솔버 / 힌트 / ECB 설계 도구 / 체크리스트 앱
- BCE 전체, UI, 1~16 중복·범위 검증 (세션 3 범위 밖)

---

### 8계층 — 이번 세션에서 만드는 것만

| 계층 | 할 일 |
|------|-------|
| **Rule** | R1~R5: 10선 합=34, 0 포함 시 `incomplete` |
| **Command** | `validate_lines(grid)` |
| **(Skill)** | pytest / fixture 준비 *(선택)* |
| **Test Loop** | Red(합≠34, 0 포함) → Green(정답 격자) |

**세션 3 범위:** Rule · Command · Test Loop — Solver / UI / BCE 전체는 후속.
