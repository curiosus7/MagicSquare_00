# STEP 1 — 보고서보내기 프롬프트

## 사용법

Mom Test 정리가 완료된 뒤 아래 프롬프트를 보낸다.  
`Report/` 폴더에 마크다운 보고서가 생성된다.

---

## 프롬프트 (복사용)

```
Report 폴더에 보고서를보내줘
```

---

## 출력 위치

```
Report/STEP1_MomTest_인터뷰보고서.md
```

---

## 보고서 포함 항목

- 개요
- 페르소나
- 인터뷰 답변 (과거 사실) + Q&A 로그
- 표면 문제 (솔루션 섞인 문장)
- 진짜 문제 (한 문장)
- Mom Test 해석 (멘토 노트)
- 참고 자료
