# STEP 1 — Mom Test 종료·정리 프롬프트

## 사용법

인터뷰가 충분히 진행된 뒤 아래 프롬프트를 보낸다.  
AI가 워크북 4개 섹션(페르소나, 과거 사실, 표면 문제, 진짜 문제)으로 정리한다.

---

## 프롬프트 (복사용)

```
Mom Test 종료하고 정리해줘
```

---

## 기대 출력

1. **페르소나** — 인터뷰 대상 한 줄 정의
2. **인터뷰 답변 (과거 사실)** — 표 형식 + Q&A 로그
3. **표면 문제** — 솔루션이 섞인 문장 (금지 목록)
4. **진짜 문제** — 한 문장
5. **멘토 노트** — 검증된 것 / 미검증 / 다음 질문 후보

---

## 후속 작업

정리가 끝나면 `STEP1_보고서_보내기.md` 프롬프트로 `Report/` 폴더에 보고서를 저장한다.
