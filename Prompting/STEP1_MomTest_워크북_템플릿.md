# STEP 1 — Mom Test 워크북 템플릿

## 사용법

인터뷰 전·후에 아래 템플릿을 채운다.  
솔루션·기능·도구 이름은 **표면 문제** 칸에만 따로 모으고, **진짜 문제**에는 넣지 않는다.

---

## 프롬프트 (복사용)

```
## Mom Test 워크북 — MagicSquare_00

### 페르소나:
[이름/익명], [역할], [관련 상황 1줄]

### 인터뷰 답변 (과거 사실):
- 마지막으로 비슷한 일을 한 때: [언제 / 어떤 상황]
- 그때 실제로 한 일: [행동]
- 들인 시간·비용: [숫자]
- 그때 느낀 점: [감정/결과]
- 그 이후에도 반복됐는가: [예/아니오 + 빈도]

### 표면 문제 (금지 — 솔루션 섞인 문장):
- "[○○ 앱/도구/기능]이 있으면/없어서 …"
- (인터뷰 원문 그대로 적고, 솔루션 단어에 표시)

### 진짜 문제 (한 문장):
[주어]는 [상황]에서 [반복 행동] 때문에 [측정 가능한 손실]을 겪는다.
```

---

## 작성 기준

| 섹션 | 기준 |
|------|------|
| **페르소나** | 실제 인터뷰한 한 사람. 가상의 평균 사용자 금지 |
| **인터뷰 답변** | 미래·가설 금지. "지난번에 ~했다"만 |
| **표면 문제** | 앱·AI·솔버·체크리스트 등 해법 단어 포함 문장 |
| **진짜 문제** | 솔루션 단어 제거, 행동·시간·손실이 드러나는 한 문장 |
