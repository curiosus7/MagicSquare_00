## Mom Test 워크북 — 작성 가이드

### 1. 페르소나
**“누구에게”** 인터뷰했는지, **구체적인 한 사람**으로 씁니다. 가상의 평균 사용자가 아니라 실제 대화한 사람입니다.

| 나쁜 예 | 좋은 예 |
|--------|--------|
| “퍼즐 좋아하는 사람” | “서울 ○○초 5학년 담임, 수학 12년차, 주 2회 수학 활동 담당” |
| “교육에 관심 있는 부모” | “초등 3학년 자녀, 주말에 학습지·퍼즐 앱 쓰는 맞벌이 부모” |

**작성 형식 예:**
> ○○(직업/역할), ○○ 상황에서 ○○ 행동을 하는 사람

---

### 2. 인터뷰 답변 (과거 사실)
**Mom Test 핵심:** 미래 의견·가설이 아니라 **이미 일어난 일**만 적습니다.

| 금지 (가설/미래) | 허용 (과거 사실) |
|-----------------|------------------|
| “앱이 있으면 좋겠다” | “지난달 수업 준비에 3시간 썼다” |
| “Magic Square 앱을 쓸 것 같다” | “작년에 퍼즐 워크시트 20장 직접 만들었다” |
| “이런 기능이 필요하다” | “학생 5명이 3×3 단계에서 막혀서 개별 설명했다” |

**기록 형식 예:**
- “마지막으로 ○○한 때: [날짜/상황]”
- “그때 한 일: [구체적 행동]”
- “그 결과: [시간·비용·감정]”

---

### 3. 표면 문제 (금지 — 솔루션 섞인 문장)
인터뷰에서 나온 말 중 **제품/기능이 이미 들어간 문장**을 따로 모읍니다.  
이건 **진짜 문제가 아니라** “이미 정한 해법”일 가능성이 큽니다.

| 표면 문제 (솔루션 섞임) | 왜 금지인가 |
|------------------------|------------|
| “Magic Square 앱이 없어서 불편하다” | ‘앱’이 해법 |
| “3×3 퍼즐 생성기가 필요하다” | ‘생성기’가 해법 |
| “AI가 힌트를 주면 좋겠다” | ‘AI 힌트’가 해법 |
| “앱스토어에 마방진 게임이 없다” | ‘게임/앱스토어’가 해법 |

이 섹션은 **버리거나 재해석**하는 용도입니다.

---

### 4. 진짜 문제 (한 문장)
표면 문장에서 **솔루션 단어를 제거**한 뒤, **행동·비용·감정**이 드러나는 한 문장으로 압축합니다.

**변환 예:**

| 표면 (금지) | 진짜 문제 (한 문장) |
|------------|-------------------|
| “마방진 앱이 없어서 수업 준비가 힘들다” | “수업 전에 난이도 맞는 퍼즐을 고르고 설명 자료를 만드는 데 매번 2시간 이상 든다.” |
| “힌트 기능이 필요하다” | “학생이 막혔을 때 다음 단계를 알려주지 못해 수업이 끊기고, 같은 설명을 반복한다.” |
| “게임화된 학습이 필요하다” | “아이가 종이 퍼즐은 10분 안에 그만두고, 부모가 매번 새 문제를 찾아야 한다.” |

**좋은 진짜 문제 문장 조건:**
- 주어 = 실제 행위자 (교사, 부모, 학생 등)
- 동사 = **이미 한 행동** 또는 **반복되는 고통**
- 숫자·시간·빈도가 있으면 더 좋음
- “앱/AI/게임/플랫폼” 같은 단어 없음

## Mom Test 워크북 — MagicSquare_00

### 페르소나
4×4 부분 마방진(빈칸 2개)을 수업 실습으로 손 계산·검증하며 다루는 학습자. ECB(Entity–Control–Boundary) 설계 분류와 실패 조건 도출 과제를 수행함.

---

### 인터뷰 답변 (과거 사실)

| 항목 | 내용 |
|------|------|
| **언제** | 수업 실습과제로 **한 번** 수행 |
| **과제** | 4×4 격자, 합=34, 빈칸 2곳에 1~16 중 빠진 숫자 채우기 |
| **병행 작업** | ECB 분류(Entity/Control/Boundary) + 실패 조건 3가지 이상 도출 |
| **막힌 순간** | 숫자 2개를 넣은 뒤 **검증에 20분** 소요 |
| **그때 한 일** | 행·열·대각선 합을 맞췄다고 확인했으나 **대각선 하나를 빼먹음** |
| **결과** | 잘못된 검증을 전제로 **20분을 소모** |
| **막혔을 때 보던 것** | 숫자 리스트 |

**미확인 (인터뷰 종료 시점):** 대각선 누락을 **어떻게** 깨달았는지, 최종 제출 여부, ECB/실패 조건 작성에 든 시간.

---

### 표면 문제 (금지 — 솔루션 섞인 문장)

인터뷰 중 학습자가 직접 말한 솔루션형 문장은 없었음. 다만 과제 맥락에서 **표면 문제로 오기 쉬운** 문장들:

- ❌ “`SquareValidator` 같은 검증기가 필요하다”
- ❌ “대각선까지 자동 체크하는 솔버가 있으면 좋겠다”
- ❌ “ECB 설계 도구가 있으면 실습이 쉬울 것이다”
- ❌ “실패 조건 체크리스트 앱이 필요하다”

→ 전부 **해법이 이미 들어간 문장**이라 진짜 문제로 쓰지 않음.

## Mom Test 해석 (멘토 노트)

**검증된 것**
- 문제는 “마방진이 어렵다”가 아니라 **검증 단계에서의 누락·시간 손실**이다.
- 숫자 채우기보다 **“맞다고 확신하는 과정”**이 병목이다.
- 20분이라는 **측정 가능한 비용**이 있어, 문제가 실제 행동에서 나왔다.

**아직 검증 안 된 것**
- 일회성인지, 다른 크기/빈칸 수에서도 반복되는지
- 코드로 풀 때도 같은 누락이 생기는지 (이번 인터뷰는 손 검증 중심)
- ECB·실패 조건 작성이 별도 고통인지

**다음 인터뷰 질문 후보** (솔루션 없이)
- “그 실습 말고, 비슷하게 검증하다 시간 날린 적 또 있어?”

---

## 1. 마지막으로 틀렸을 때

### Q1
> 마지막으로 4×4 부분 마방진 답이 **틀렸다고 알게 된 순간**, 그 직전까지 **실제로 뭐 하고 있었어?**

**✅ Mom Test 준수** — 특정 과거 순간, 구체적 행동을 묻는다.

---

### Q2
> 만약 행·열·대각선을 자동으로 검증해 주는 기능이 있었다면, **틀린 걸 더 빨리 알았을 것 같아?**

**❌ Mom Test 위반** — 가설(“~일 것 같아?”) + 솔루션(자동 검증)을 섞었다.  
**✅ 고친 버전:** 그때 **틀렸다는 걸 어떻게** 알게 됐어?

---

## 2. 검증/확인 비용

### Q3
> 빈칸 두 개 채운 뒤, 행·열·대각선 합이 맞는지 **마지막으로 확인하는 데 몇 분** 걸렸어?

**✅ Mom Test 준수** — 측정 가능한 과거 비용(시간)을 묻는다.

---

### Q4
> 검증 체크리스트나 도구가 있으면 **20분 낭비를 줄일 수 있을까?**

**❌ Mom Test 위반** — 미래·솔루션 효과를 묻고, 본인 경험 대신 제품 가치를 검증하려 한다.  
**✅ 고친 버전:** 그 **20분 동안**, 합 맞춰본 순서가 어땠어? (행 → 열 → …)

---

## 3. 포기·중단 순간

### Q5
> 4×4 부분 마방진 풀다가 **중간에 멈춘 적** 있어? **마지막으로** 멈췄을 때, 그때까지 **뭐 했어?**

**✅ Mom Test 준수** — 포기/중단의 구체적 과거 사례와 행동을 묻는다.

---

### Q6
> 너무 어려우면 **힌트 버튼**이 있으면 **계속할 것 같아?**

**❌ Mom Test 위반** — “~할 것 같아?” 가설 + 기능 제안.  
**✅ 고친 버전:** **마지막으로** 포기했을 때, **뭐 때문에** 그만뒀어?

---

## 4. 같은 문제를 다시 풀 때

### Q7
> **같은** 4×4 부분 마방진 문제를 **두 번째로** 풀었을 때, **첫 번째랑 뭐가 달랐어?**

**✅ Mom Test 준수** — 반복 경험의 과거 비교, 실제 차이를 묻는다.

---

### Q8
> 다시 풀 때 **이전 답이나 풀이를 저장**해 두면 **도움이 될까?**

**❌ Mom Test 위반** — 기능 필요성·가설 질문.  
**✅ 고친 버전:** 두 번째로 풀 때, **첫 번째 때 적어 둔 메모나 흔적**을 봤어?

---

## 5. 다른 사람에게 설명/공유할 때

### Q9
> **마지막으로** 누군가에게 부분 마방진 풀이를 **설명했을 때**, 그 사람이 **어디에서** 막혔어?

**✅ Mom Test 준수** — 설명 경험의 구체적 과거 사례, 관찰 가능한 사실.

---

### Q10
> 설명할 때 **격자를 그려 주는 앱**이 있으면 **더 잘 이해시킬 수 있을까?**

**❌ Mom Test 위반** — 솔루션 + 효과 가설.  
**✅ 고친 버전:** 설명하다가 **말이 막혔을 때**, 그때 **실제로 뭐라고** 했어?
